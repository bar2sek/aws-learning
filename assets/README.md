# 🖼️ Vault Assets & Media

This directory stores embedded media, architecture diagrams, charts, screenshots, and visual reference materials referenced across the knowledge vault.

Obsidian is configured to route pasted images and attachments directly into this folder (`attachmentFolderPath: "assets"`).
